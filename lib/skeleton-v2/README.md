## Design rules

- Every user-facing entity has `id` (cuid), `slug` (UNIQUE), `isActive`, `status`
- Soft delete by default (`isActive = false`, `status = 'inactive'`)
- All UI strings in Spanish (castellano); code identifiers in English
- TypeScript strict mode — no `any` allowed
- Tests pass green before merge (3x stable)
