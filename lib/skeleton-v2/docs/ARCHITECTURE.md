## Architectural rules (enforced by `dependency-cruiser`)

1. `domain` ⇐ `application` ⇐ `infrastructure` ⇐ `presentation` — no upward imports.
2. `domain` and `application` cannot import `@prisma/client`, `react`, or `next`.
3. `application` depends on Repository INTERFACES, never on `*Impl` concrete classes.
4. No circular dependencies.
